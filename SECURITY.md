# Security policy

Only `main` is supported. This is a paper-trading information system, not a live broker.

Report vulnerabilities privately via GitHub Security Advisories. Do not open a public issue with exploit detail. Use synthetic data only.

In scope: strategy router, risk gate, policy, audit redaction, kill switch, CI tripwire.

Built-in protections: paper default, withdraw scope rejected, secret tripwire, hash-chained audit, depeg and day-loss halts.
